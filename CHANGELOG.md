# Changelog

## 1.0.0 — 2026-10-06

- BBIR 2 materials, RGBA pixels, face UV/visibility and numeric bone animations; BBIR 1 migration.
- Bounded mirror/repeat language macros and transactional add/replace patches.
- Deterministic textured PNG rasterization, pose sampling and independent PNG interoperability.
- Shared browser-compatible compiler in the Blockbench bridge, FXL file loading and task model selection.
- Doctor diagnostics, owned process-tree cancellation and 4.10 native animation axis migration.
- Standalone CLI/MCP/plugin ZIP with hashes/licenses, clean-directory smoke and official MCP client/schema tests.
- Actual Blockbench web 5.2.1 model/plugin checks and comprehensive release documentation.

Live provider accounts, desktop host tests and game-specific export codecs remain explicitly outside verified release evidence.

## 0.1.0 — 2026-10-06

- Initial Formixel TypeScript workspace foundation.
- FXL/BBScript parsing, BBIR validation, deterministic geometry and stable bbmodel export.
- Local build/import/export/inspect/validate/patch/render CLI and validated provider generation/task execution.
- Primary Codex CLI/Claude Code planners; optional explicit OpenAI/Anthropic API adapters.
- Minimal stdio MCP and browser Blockbench plugin bridge.
- Tests, cross-platform CI, contributor/security/architecture and maintenance documentation.

This is a foundation release, not completed texture/animation/game-export support.
